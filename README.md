## 🚀 Proyectos destacados

### 🛒 Metric Mindset — Predicción de intención de compra

**Proyecto final de Data Science | Soy Henry**

Proyecto colaborativo de Machine Learning orientado a predecir la intención de compra de usuarios en e-commerce, utilizando el dataset *Online Shoppers Purchasing Intention*.

**Mi rol: ETL & Feature Engineering**

#### 🔹 ETL y calidad de datos

- Procesamiento inicial de **12.330 registros y 18 columnas**.
- Validación de esquema, valores nulos y tipos de datos.
- Identificación y eliminación de **125 registros duplicados**.
- Detección y documentación de outliers mediante el método IQR.
- Validaciones de consistencia lógica entre variables.
- Generación de un dataset procesado de **12.205 registros**.
- Preparación de datos para Machine Learning y visualización en Power BI.

#### 🔹 Feature Engineering

- Creación de **5 características derivadas** del comportamiento de navegación:
  - `duracion_total`
  - `paginas_totales`
  - `duracion_promedio_pagina`
  - `proporcion_paginas_producto`
  - `es_visitante_recurrente`
- División estratificada en entrenamiento y prueba.
- Implementación de OneHotEncoder y StandardScaler.
- Construcción de un pipeline de preprocesamiento con ColumnTransformer.
- Ajuste de transformaciones exclusivamente sobre entrenamiento para evitar data leakage.
- Generación de matrices procesadas con **78 características** para modelado.
